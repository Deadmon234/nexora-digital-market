# Nexora Digital Market

Plateforme e-commerce multi-vendeurs avec Next.js et Spring Boot.

## Structure du projet

- `frontend/` : application Next.js (TypeScript, Tailwind, app router)
- `backend/` : application Spring Boot (Java, Maven)

## Démarrage

### Frontend
- Installer Node.js et npm
- `cd frontend`
- `npm install`
- `npm run dev`

### Backend
- Installer Java 17+ et Maven
- `cd backend`
- `mvn spring-boot:run`

## Fonctionnalités prévues

- authentification admin / vendeur / client
- création et gestion de boutiques par les vendeurs
- gestion des produits et du stock
- administration globale du site
